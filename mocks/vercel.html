카드 게임으로 푸는 최장 증가 부분수열

같은 문제를 두 방법으로 한 단계씩. 왼쪽은 표를 채우는 동적계획법, 오른쪽은 카드를 쌓는 페이션스 정렬이다. 단계마다 무엇을 했고 왜 그런지는 오른쪽 여백의 번호 주석에 적었다.

동적계획법 — 표 채우기

dp[i] = a[i]로 끝나는 가장 긴 증가 부분수열의 길이

a[4] = 5 < a[5] = 8 → 이어 붙일 수 있음

  1. LIS_DP(a[1..n])
  2. for i = 1 to n
  3. dp[i] = 1; prev[i] = 0 // a[i] 혼자서 길이 1
  4. for j = 1 to i − 1
  5. if a[j] < a[i] and dp[j] + 1 > dp[i]
  6. dp[i] = dp[j] + 1; prev[i] = j
  7. best = dp가 가장 큰 위치
  8. return dp[best] // prev를 거꾸로 따라가 수열 복원

  1. LIS_Patience(a[1..n])
  2. piles = 0
  3. for i = 1 to n // 카드 a[i]를 뽑는다
  4. k = 이분검색: a[top[k]] ≥ a[i]인 가장 왼쪽 더미
  5. back[i] = (k > 1) ? top[k − 1] : 0
  6. if k == piles + 1: piles = piles + 1
  7. top[k] = i // 더미 k 위에 올림
  8. return piles

2

기존 더미에 올리기 II · 페이션스 · 카드 a[6] = 6

무엇을더미 3의 8 위에 6을 올리고, 왼쪽 더미 맨 윗장 5를 가리키는 화살표를 남긴다.

왜맨 윗장은 "길이 3짜리 수열이 끝날 수 있는 가장 작은 값"이다. 8보다 작은 6으로 끝나야 뒤에 더 많은 수를 붙일 수 있다.

두 패널은 같은 수열을 읽는다. 끝까지 가면 두 결과와 비교 횟수를 나란히 보여 주는 표가 나온다.
